# Ingoair-Spornsor Int — Version 1

This is a free, static first version of the customer registration website.

## What it currently does
- Mobile-friendly customer registration form
- Collects basic customer details
- Validates required fields
- Creates a registration reference number
- Shows a confirmation screen
- Saves demo registrations to the browser's localStorage

## Important limitation
This version does NOT provide a shared online customer database. localStorage means records stay in the browser/device where they were submitted.

## Recommended next version
Connect the form to a free backend such as:
1. Google Apps Script + Google Sheets, or
2. Supabase

That will allow customers on different phones to register and allow the business administrator to view the same records.
